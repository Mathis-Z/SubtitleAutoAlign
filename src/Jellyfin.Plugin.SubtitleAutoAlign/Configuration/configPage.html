Subtitle Auto Align

Automatically runs ffsubsync on newly downloaded subtitles for movies, writing an aligned copy alongside the original.

Align new subtitles as they appear. Does not affect "Align all subtitles" below.
Leave empty to auto-detect: uses the ffsubsync binary bundled with this plugin (Linux x64), or falls back to "ffsubsync" on PATH. Set an explicit path to override.
Optional extra CLI arguments, e.g. --max-offset-seconds 60

Existing subtitles

Search all library folders (including subfolders) for subtitle files next to their videos and align every one that doesn't have an aligned copy yet. This runs the "Align all subtitles" scheduled task; you can follow its progress, cancel it or schedule it under Dashboard > Scheduled Tasks.
